待解決疑問

下列項目會改變研究操作或資料語意；部分已有暫行方案，仍需與指導教授確認後定案。

待研究設計共識
待研究程序確認 01

未完成作答與中途退出

目前：正式 Task 每題須有答案與理由；提交後由 LLM／規則初判，再由研究者全題核對。漏答拒絕提交，LLM 失敗保留 failed，不算學生答錯。

需決定：正式中止、缺漏與排除規則；不是再決定把 unanswered 當作錯誤排入哪裡。

影響：避免把未嘗試或系統故障混成學生的學習錯誤。

已採方案、持續觀察 02

Disclosure D0／D1 的資訊邊界

目前：私有 context 可讀正解、修正解說與材料；限制的是提前直接完成解題，不是禁止全部相關史實。

可見邊界：可用答案相關要素、比較與線索，學生已答對的部分可確認；授權前不代答仍未修正的部分。

觀察限制：已移除字詞比對，獨立語意審查可觀察或交付前有限修正；仍可能誤判，不保證零洩漏。

已實作的暫行規則 03

Historical EBL 的完成標準

獨立完成：認知需修正之處、說明原因、修正答案及理由符合原題標準；可跨回合累積，不另要求史料引用或 HT 技能。

輔助完成：D4 仍未修正先提供正解與理由，再給一次重述機會後轉下一題；不強求反覆完美。

資料區別：獨立修正與 assisted restatement 分開記錄；模型僅自報 RESOLVED 不能跳過完成條件。

HAT 候選方向 04

後測流程與正式測量題本

目前：系統已串接三題 Engagement 活動回饋與兩題 HAT 文字作答，全部為 Pseudo 題，供測試流程；Error-Elicitation Task 不是前測或後測。

需決定：正式 Engagement 量表與量尺、HAT 題目、史料、維度、rubric、測量時點、題數、時間與評分者一致性。示範題數與順序不等於正式設計已凍結。

驗收方向：專家審查、小量試測與盲評複核；不要把寫作流暢、角色沉浸或 HT tags 直接當成 outcome 分數。

最高優先待與教授確認 05

正解公布與五分鐘收尾的測量影響

目前：已採後測前修正：D4 回饋後重述；到期則只對已談到的未完成目前題目另開收尾，不延長 Chat。

需決定：確認正解暴露、各組介入差異與額外重述時間如何標準化及解釋；不是待開發舊的略過按鈕。

影響：保留訂正流程，同時區分獨立修正與讀過答案後的重述，避免混淆測量。

設計與核心程式已對齊 06

EBL 與 Historical Thinking 的角色分工

已確認：EBL 是 02／04 主要互動教學鷹架；Role-play 是另一個因子。

共用基礎：HT 幫助四組 AI 產生合理的歷史回應，不明示要求學生練習指定 HT 技巧。

程式現況：已不再把 HT operator 或額外引用要求當作獨立完成門檻；實際介入忠實度仍需抽樣比較。

最高優先待討論 07

人物時間與史料素材的界線

目前：人物仍不能知道未來或把後世材料當成親身記憶；學生材料區不等於人物的既有知識。

需區分：後來翻譯較早文件，與材料描述未來事件，是不同情況；需分清作品、原始資料與出版日期。

未核准：是否允許人物討論學生帶來的後世材料尚未定案，本次沒有改人物時間規則。

最高優先正式驗收 08

四事件素材、人工判準與專家審查

目前：LLM 提供初判，研究者對每份作答的所有題目確認最終答案與理由判定後，才進入 AI 互動；系統流程完成不等於判分效度已驗證。

必要工作：確認跨事件史料類型、數量與閱讀負荷，編製逐題書面判準並交歷史專家審視；保留合理等義回答、理由通過條件與爭議判例。

影響：錯誤判題會製造假的 EBL 目標；素材差異也可能被誤認為 Condition 效果。
